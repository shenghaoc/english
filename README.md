# English

This repo is a collection of properties of standard English that prevent me from accepting well-meaning English language advice.

I will write only the main points and leave the details to AI.

1. For a stress-timed language, unstressed syllables are not **enunciated** in full
2. Connected speech is not slurring, it is a very natural byproduct of not replacing word-final consonants with **glottal stops**
3. For a stress-timed language, **rising pitch** influenced by right-dominant Minnan sandhi is not in any way better for making statements
